## 修复「前端白屏」问题
- 现象：页面全白，首页/编辑页 HTTP 均 200，Vite 日志无编译错误。
- 根因：Vite 开发服务器内存模块缓存损坏——把 NavBar.jsx 误记为空文件（transform 仅 1 行、sourcesContent 为 ""，无 export default），导致 MainApp import NavBar 报 `does not provide an export named 'default'`，React 卸载整棵树 → 白屏。磁盘文件本身完整（3298B）。
- 修复：kill 3000 端口进程 → 清空 node_modules/.vite → 重启 npm run dev，模块重新 transform 后恢复（168 行、含 export default）。
- 经验：多次热更新（尤其对同一文件反复 Edit）可能触发 Vite watcher 缓存不同步；排查此类白屏可先用无头 Chrome `--enable-logging=stderr --dump-dom` 抓 console 报错定位。
